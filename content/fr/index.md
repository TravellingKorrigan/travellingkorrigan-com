# De petits jeux pour les moments calmes

Travelling Korrigan est un label indépendant qui fait de petits jeux construits sur les standards du web. Jouez-y dans un navigateur, sur votre téléphone ou votre ordinateur, ou installez-les depuis les stores.

Les jeux n’ont pas de pistage, pas d’achats intégrés et pas d’astuces pour vous rendre accro. [Pourquoi je les fais](/fr/a-propos/).
